# 🔒 Password Strength Checker

A Python-based tool that evaluates user-entered passwords for their strength and scores 1 to 5 on the basis of the strength of the password entered.

---

## 🚀 Features

- **Length check**: Requires minimum 8 characters.
- **Uppercase & lowercase detection**: At least 1 uppercase and 3 lowercase letters.
- **Symbol inclusion**: Ensures presence of special characters.
- **Numeric sequence evaluation**: Penalizes consecutive digits.
- **Input sanitization**: Validates allowed character sets.
- **Scoring system**: Outputs a score out of 10, with suggestions to strengthen weak passwords.

---

   git clone https://github.com/anonym-saurab/PasswordStrengthChecker.git
